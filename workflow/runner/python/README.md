# Aixand Runner Client

Python client for the local Aixand job runner. Install the `aixand-suite-runner-client`
package in a Python 3.11 or newer application environment and import `runner_client`.
The Runner service is installed separately; this library does not install or
start a service. See the [Runner documentation](https://github.com/Aixand/aixand-suite/tree/main/workflow/runner)
for its protocol, installation and lifecycle.
