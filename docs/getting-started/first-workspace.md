# Onboarding

Onboarding connects your providers and adds projects to the workspace.
Complete [configuration](configuration.md) first, then follow the setup screens:

| Step | What you do |
| --- | --- |
| 1. [Choose providers](../onboarding/choose-providers.md) | Select Codex, OpenCode, or both |
| 2. [Install provider software](../onboarding/install-providers.md) | Use detected software or install what is missing |
| 3. [Create a profile and sign in](../onboarding/profiles-sign-in.md) | Connect the selected provider |
| 4. [Add projects](../onboarding/projects.md) | Select folders on the workspace host |
| 5. [Finish setup](../onboarding/finish.md) | Open the workspace and check your first chat |

The workspace password and provider sign-in are separate. With Client, providers
and projects belong to Server.

Screenshots show the real UI in its browser preview, using simulated providers,
profiles, and folders. Preview-only controls do not appear in normal setup.
