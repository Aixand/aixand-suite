# Configure Aixand

After installation, follow the guide for your application:

| Application | Next step |
| --- | --- |
| **Suite — This computer** | [Configure the local workspace](../guides/configure-suite.md); networking is automatic |
| **Server** | [Configure the workspace host](../guides/configure-server.md), then choose SSH or HTTPS access |
| **Client** | [Connect to the configured Server](../guides/configure-client.md) |
| **Suite — Server connection** | Use the [Client connection steps](../guides/configure-client.md) |

Next: [Onboarding](first-workspace.md).
