# Choose an installation

| Application | Install it when… |
| --- | --- |
| [Aixand Suite](install-suite.md) | You want to run your workspace on this computer. It can also connect to Server. |
| [Aixand Server](install-server.md) | This computer will host projects, agents, and running work. |
| [Aixand Client](install-client.md) | You want the interface on this computer and the workspace on an existing Server. |

For one computer, choose **Suite**. For separate computers, install **Server** on
the host and **Client** on your desktop.

Each guide includes Windows and Linux/macOS commands. No source checkout or
developer toolchain is required.

Want your agent to install it? Use the [agent installation instructions](../../agent-installation-instruction.md).
