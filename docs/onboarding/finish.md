# Finish onboarding

After **Finish setup** or **Skip for now**, the workspace opens. Confirm you are
connected to the intended local workspace or Server.

## Check your first chat

1. Select a project, or [add one](../guides/projects.md) if you skipped project setup.
2. Open **New chat** and select the configured provider/profile.
3. Send:

   > Reply with exactly aixand-install-ok. Do not run tools or change files.

Expect a completed `aixand-install-ok` reply. This request can consume provider
quota. If it fails, inspect the provider error and [troubleshooting](../guides/troubleshooting.md).

Close and reopen the workspace. The saved conversation should load without
resending the prompt. Keep it for reference or remove it through its controls.
