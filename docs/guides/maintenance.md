# Maintain your workspace

| Step | Guide |
| --- | --- |
| 1. Update an application, component, or tool | [Updates](updates.md) |
| 2. Diagnose connection, provider, or execution problems | [Troubleshooting](troubleshooting.md) |
| 3. Preserve data, restore a workspace, or uninstall | [Backup and removal](backup-and-removal.md) |

Check the selected workspace host before maintenance. Finish active work before
stopping services or installing changes.

For Server operations, use its [maintenance reference](../../apps/server/docs/installation.md#repair-reset-and-removal).

Start with [Updates](updates.md), or choose the task you need.
