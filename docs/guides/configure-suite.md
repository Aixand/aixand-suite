# Configure a local Suite workspace

[Install Suite](../getting-started/install-suite.md), then open it.

## Choose the workspace

1. Select **This computer**.
2. Review the workspace location and required tools/licenses.
3. Choose a tool installation mode:

   | Mode | Use it when |
   | --- | --- |
   | **Isolated** | You want workspace-private tools and manager settings; recommended for a fresh setup |
   | **Shared** | You want compatible normal-user tools and settings available outside this workspace |

4. Complete tool setup and create the workspace password privately.
5. Continue with [onboarding](../getting-started/first-workspace.md).

Keep an existing workspace's saved installation mode. Local connections need no
SSH tunnel, HTTPS proxy, or manual origin configuration.

## Check setup

Open the workspace and confirm it is **This computer**. After provider setup,
complete the test conversation, then close and reopen the workspace to check it
reconnects.

To use a remote workspace instead, select Server in the launcher and follow
[Client configuration](configure-client.md).
